# KAUSYNC — CALIBER 2026

Live prototype: https://owfarisz.github.io/caliber-final/

Two-role spare-parts planning from six audited synthetic workbooks, covering 7,481 materials. Includes interactive scenarios, explainable stock policies and a visual Indonesian audit.

## Static preview

```sh
npm ci
npm run build:pages
```

GitHub Actions deploys `pages-dist/` to GitHub Pages on every main-branch push. `PAGES_BASE` defaults to `/caliber-final`. The browser loads the canonical JSON projection and executes the same deterministic engine used by the full Next.js application. No server APIs, authentication or persistent scenario storage are provided by this static preview. The complete local deliverable includes read-only SQLite and Next.js APIs.

See [data audit](https://owfarisz.github.io/caliber-final/audit-report.html), [PM feedback](PM_FEEDBACK.md) and [TRD](TRD.md). Price interpretation, exposure assumptions and incomplete asset attribution are explicitly labeled. The model is illustrative, not a calibrated failure predictor.

## Verification

```sh
node --experimental-strip-types --test tests/engine.test.ts
```

Phone layout uses bottom navigation, full-width content and larger touch controls. Screenshots and viewport test evidence are generated by `scripts/verify-pages.mjs`.
